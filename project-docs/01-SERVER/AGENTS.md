# Instruksi scope Backend Server

Baca [instruksi global](../00-GLOBAL/AGENTS.md) dan [matriks acuan](../00-GLOBAL/SOURCE-OF-TRUTH.md). Scope ini memegang REST API v1, skema, migrasi, autentikasi, otorisasi, validasi, transaksi, stok dan penyimpanan. Source aplikasi ada di `Motifnesia-Server/`.

Baca manifest route v1 dan legacy, middleware, Gate, Form Request, controller, service yang dipakai, model dan migration. Pastikan bukti sebelum mengubah API atau mengklasifikasikan skema. Tautkan UC, skenario, KF, dan bukti implementasi sebelum mengklaim perubahan.

Perubahan kontrak, izin, data, atau lifecycle dibahas dengan Web dan Mobile. Scope Server menawarkan kontrak dan implementasi backend bagi gateway. Detail vendor tetap TBD. Catat keputusan atau konflik menurut [aturan global](../00-GLOBAL/GLOBAL-RULES.md). Wewenang untuk mengubah kode mengikuti tugas yang disetujui.
