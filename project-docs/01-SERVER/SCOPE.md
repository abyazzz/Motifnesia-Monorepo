# Scope Backend Server

Anggota Backend Server bertanggung jawab atas REST API v1, skema, migrasi, autentikasi, otorisasi, validasi, transaksi, stok dan penyimpanan. Tumpukan teknologi utama adalah Laravel 12, Sanctum, MySQL dan Laravel Blueprint.

Rancangan mencakup ERD, Class Diagram, API, dan skema. Perubahan mengikuti [traceability](../00-GLOBAL/TRACEABILITY-MATRIX.md) dan [keputusan tim](../00-GLOBAL/DECISION-LOG.md).

Perubahan kontrak, izin, data, atau lifecycle dibahas dengan Web dan Mobile. Scope Server menawarkan kontrak dan implementasi backend bagi gateway. Detail vendor tetap TBD. Perubahan kontrak lintas scope ditinjau oleh anggota yang memegang implementasi terkait.
