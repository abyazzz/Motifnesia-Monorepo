# Design system Mobile

Warna aktual Customer Web mencakup gold #c9a84c, ivory #f5f0e8, dan dark #1c1a16. Flutter memakai gold #c9a84c dan ink #111111. Admin Web memakai Nunito dan Plus Jakarta Sans. Sumber ada di [layout Customer](../../../../Motifnesia-Client-Web/resources/views/customer/layouts/mainLayout.blade.php), [layout Admin](../../../../Motifnesia-Client-Web/resources/views/admin/layouts/mainLayout.blade.php), dan [tema Flutter](../../../../Motifnesia-Client-Mobile/lib/core/theme/motifnesia_theme.dart).

Panduan berikut berstatus PROPOSED.

| Komponen | Panduan |
| --- | --- |
| Typography | Hierarki judul, teks, label dan helper konsisten. |
| Color roles | Warna merek untuk aksi, warna semantik untuk status dan teks kontras. |
| Spacing | Skala usulan 4, 8, 16, 24 dan 32 px/logical px. |
| Button | Aksi utama terlihat, sekunder lebih ringan, disabled dan busy jelas. |
| Input dan dropdown | Label terlihat, nilai awal, helper, validasi dekat field. |
| Card dan table | Ringkasan dipindai, tabel Web dapat discroll, Mobile memakai kartu. |
| Modal/dialog | Judul, isi, batal dan konfirmasi dengan fokus terkelola. |
| Navigation | Customer memakai akses katalog dan akun; admin mengikuti ability. |
| Badge/status | Status pembayaran dan pesanan dibedakan dengan teks. |
| Alert, loading, empty | Sampaikan hasil server, progres, data kosong dan tindakan lanjutan. |
