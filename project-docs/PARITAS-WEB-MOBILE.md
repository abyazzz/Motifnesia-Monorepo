## Perbedaan implementasi

Web menggunakan Blade, form dan sesi server-side. Flutter menggunakan widget, navigasi responsif dan penyimpanan sesi sesuai platform. Perbedaan UX dan jumlah route tidak mengubah kemampuan yang diwajibkan. Validasi, transaksi dan otorisasi mengikuti API Server yang sama. Rancang uji per UC, role dan client, termasuk hasil gagal dan izin ditolak.
