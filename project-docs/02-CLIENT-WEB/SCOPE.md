# Scope Client Web

Anggota Client Web bertanggung jawab atas render halaman, bentuk form, aset, navigasi, session Web, relay API dan UX browser. Tumpukan teknologi utama adalah Laravel 12, Blade, Vite dan sesi Web.

Rancangan mencakup sitemap, spesifikasi halaman, UI dan alur pengguna. Perubahan mengikuti [traceability](../00-GLOBAL/TRACEABILITY-MATRIX.md) dan [keputusan tim](../00-GLOBAL/DECISION-LOG.md).

Server menentukan validasi, status transaksi dan izin. Sinkronkan perubahan bentuk data, status dan aksi dengan Server. Tinjau konsistensi istilah dan alur bersama Mobile. Perubahan kontrak lintas scope ditinjau oleh anggota yang memegang implementasi terkait.
