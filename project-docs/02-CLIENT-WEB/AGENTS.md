# Instruksi scope Client Web

Baca [instruksi global](../00-GLOBAL/AGENTS.md) dan [matriks acuan](../00-GLOBAL/SOURCE-OF-TRUTH.md). Scope ini memegang render halaman, bentuk form, aset, navigasi, session Web, relay API dan UX browser. Source aplikasi ada di `Motifnesia-Client-Web/`.

Baca role dan skenario, route pada Laravel Web, MotifnesiaController, Blade target, serta API yang dikonsumsi. Layout dan route sesuai role berasal dari viewer. Tautkan UC, skenario, KF, dan bukti implementasi sebelum mengklaim perubahan.

Server menentukan validasi, status transaksi dan izin. Sinkronkan perubahan bentuk data, status dan aksi dengan Server. Tinjau konsistensi istilah dan alur bersama Mobile. Catat keputusan atau konflik menurut [aturan global](../00-GLOBAL/GLOBAL-RULES.md). Wewenang untuk mengubah kode mengikuti tugas yang disetujui.
